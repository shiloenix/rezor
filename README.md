# rezor

> A simple Bash theme for fun.

It is a lightweight Bash prompt theme with a clean, minimal look.
No framework, no dependencies — just Bash.

## Installation

```bash
mkdir -p ~/.bash_themes
```

Then put `rezor.bash` inside it:

```bash
cp rezor.bash ~/.bash_themes/rezor.bash
```

## Enable the theme

Add this line to your `~/.bashrc`:

```bash
source ~/.bash_themes/rezor.bash
```

Then reload your Bash configuration:

```bash
source ~/.bashrc
```

Your new prompt should now be active.

## Uninstall

Remove the theme:

```bash
rm ~/.bash_themes/rezor.bash
```

Then remove the corresponding `source` line from `~/.bashrc`.

Reload Bash:

```bash
source ~/.bashrc
```

## Requirements

* Bash
* A terminal with ANSI color support

No additional dependencies are required.
